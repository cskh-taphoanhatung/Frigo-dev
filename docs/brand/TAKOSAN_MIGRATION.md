## Source of truth

The supplied `takosan-brand-kit.zip` (tokens v1.1.0) is the only visual source.
Logos, wordmark, symbol, mascot poses and UI icons are the kit SVGs installed
verbatim; nothing was redrawn, typeset or generated by an image model. Palette:
coral `#FF7B6B`, green `#2E7D5B`, navy `#1F2937`, cream `#FFF8F3`, mint
`#DFF4E6`, yellow `#FFC857`. Semantic: primary action = green, accent = coral,
text = navy, surface = cream. Typography: Nunito (Google Fonts, same hosted
pattern the app already used) with `system-ui, sans-serif` fallback; the
TAKOSAN wordmark is always the supplied SVG geometry.

## Runtime asset layout

Only the assets the app uses were installed (≈230 KB); design/marketing/social
templates stay in the kit.

```
public/takosan/brand/      horizontal + stacked lockups (primary/white), wordmark, symbol, symbol-micro, takosan-og.png
public/takosan/app-icons/  favicon.svg, adaptive fg/bg SVG, icon-{16..512}.png, icon-maskable-512.png
public/takosan/mascot/     neutral, wave, thinking, celebrate, fridge, recipe, cooking, calendar, shopping (SVG)
public/takosan/ui-icons/   home, fridge, scan, recipe, meal-plan, calendar, shopping-list, profile (SVG)
```

PNG icons are derived deterministically from the kit's 1024px
`takosan-app-icon-light.png` by `scripts/generate-takosan-icons.mjs` (`sharp`
0.33.5, a direct exact devDependency, lanczos3). The maskable icon composites
the kit adaptive background + foreground so the mascot stays inside the 80 %
safe area. The OpenGraph card rasterizes the kit horizontal-lockup SVG onto a
1200×630 cream canvas. Re-run with `pnpm brand:icons <kit-dir>` (or
`node scripts/generate-takosan-icons.mjs <kit-dir>`); regeneration is
byte-stable (verified twice against the committed files).

`public/frigo/ingredients` and `public/frigo/recipes` are content, not brand, and
were not moved. `public/frigo/{brand,app-icons,illustrations}` remain on disk
for now (no runtime references from the primary shell) and can be removed once
the migration is accepted.

## Code contract

- `src/web/lib/takosan-brand.ts` — `TAKOSAN_BRAND` (name, tagline, logos,
  wordmark, symbol, mascot, appIcons, uiIcons, colors). Components read brand
  paths only from here. `FRIGO_ASSETS` is unchanged and still owns ingredient /
  recipe content paths.
- `src/web/components/common/TakosanIcon.tsx` — inline SVG renderer for the kit
  UI icon grammar (24×24, currentColor, 1.8 round stroke). Used in BottomNav
  (home/fridge/scan/meal-plan/profile) and Landing CTAs. Generic system icons
  (back, close, bell, settings, chevrons…) stay Lucide.
- `src/web/styles/takosan-tokens.css` — `--takosan-*` and semantic
  `--color-action-primary`, `--color-action-accent`, `--color-text-primary`,
  `--color-surface`. `frigo-tokens.css` now imports it and keeps every
  `--frigo-*` name as a compatibility alias (do not delete until proven).
- `tailwind.config.js` — `takosan.{coral,green,navy,cream,mint,yellow}` colours
  (with derived `green.hover/deep`, `mint.hover/deep`, `cream.deep/line/shade`,
  `coral.deep/soft` shades) and Nunito for `heading`/`body`/`sans`. The legacy
  `frigo.*` names are kept but now resolve to Takosan values, and
  `shadow-float` / `shadow-glow` derive from Takosan green `rgb(46, 125, 91)`.
